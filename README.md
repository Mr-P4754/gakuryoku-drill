# 標準学力調査たいさく デジタルドリル

12月に実施される東京書籍作成の標準学力調査に向けた、**HTML / CSS / JavaScript (SPA) + GoogleスプレッドシートDB** 構成の対策用デジタルドリルです。  
初期対象として **小学4年生・4教科（国語・社会・算数・理科）の全77単元** を収録し、将来的に他学年（1〜6年生）へシート追加だけで簡単に拡張できます。

## 主な機能

- **4教科・全77単元を全量収録**（フォローアップ・たしかめドリル・チャレンジ）
- **全11タイプの問題形式に対応**
  - 自動採点9種：単一選択（○×・4択等）、複数選択、語群穴埋め、組み合わせ（線結び）、並び替え、短答テキスト、数値・あまり入力、分数・帯分数専用3枠入力、数式・関係式入力（記号パッド付き）
  - 自己採点2種：漢字手書きマス／方眼・図形作図キャンバス（直線定規・模範作図の半透明重ね合わせ比較）、作文・自由記述（リアルタイム文字数カウント・観点チェックリスト）
- **小学4年生向け学習支援UI**
  - ふりがな（ルビ）表示ON/OFF、国語長文の縦書き／横書き切替、2ペイン表示
  - 全図版を鮮明な **オリジナルSVG** で制作（タップ拡大・ズーム対応）
  - いつでも開閉できる **計算メモ帳（手書きオーバーレイ）**
  - 単元ごとの **要点チェックカード**、**まちがえた問題だけやり直し**、**教科別ランダム模擬テスト（力だめし10問）**
- **Googleスプレッドシート連携＆教員向け簡易スコア記録**
  - 静的JSONキャッシュ（`data/*.json`）＋ Google Apps Script（GAS）Web API のハイブリッド構成で高速表示＆学校ネットワーク制限下でも安定動作
  - 児童は氏名不要の **「学校名（半角英字）＋組＋出席番号」** で学習ログをスプレッドシート `学習ログ` シートへ自動送信（オフライン時は端末に退避し次回自動再送）
  - `集計_クラス進捗` シートで単元別正答率・児童別実施回数を自動集計
- **Google Classroom 等での単元ダイレクト配布**
  - `#drill?grade=4年&subject=sansu&unit=P5MA1_005` のようにURLハッシュで特定単元を直接開けます。

## スプレッドシート構成（`標準学力調査対策_デジタルドリルDB`）

| シート名 | 用途 |
| :--- | :--- |
| `マスタ_教科一覧` | 公開対象の学年・教科・シート名・テーマカラー・公開フラグ |
| `4年_単元ガイド` | 全77単元のねらい・要点チェック・例題 |
| `4年_国語` / `4年_社会` / `4年_算数` / `4年_理科` | 各教科の問題データベース（共通20列スキーマ） |
| `学習ログ` | 児童端末から送信されるスコア履歴 |
| `集計_クラス進捗` | `QUERY` 関数による教員用自動集計ダッシュボード |

## 教員向けセットアップ手順（GAS Web API の有効化）

本アプリは同梱の静的JSONキャッシュにより **GitHub Pages 上で設定不要ですぐに演習可能** です。  
さらに **スプレッドシート編集の即時反映** および **児童スコアの `学習ログ` シート自動記録** を有効にするには、以下の3ステップでGASをデプロイしてください。

1. Googleスプレッドシート「`標準学力調査対策_デジタルドリルDB`」を開き、メニューから **「拡張機能」→「Apps Script」** を開く。
2. 本リポジトリの [`gas/Code.gs`](gas/Code.gs) の内容をすべて貼り付けて保存する。
3. 右上の **「デプロイ」→「新しいデプロイ」** から種類を **「ウェブアプリ」** に設定し、以下でデプロイする。
   - **実行するユーザー**: 自分
   - **アクセスできるユーザー**: 全員
4. 発行されたURL（`https://script.google.com/macros/s/.../exec`）を [`js/config.js`](js/config.js) の `GAS_API_URL` に記入してコミット＆プッシュする（またはアプリ右上の設定アイコンからも登録できます）。

## 他学年（1〜3年、5〜6年）への拡張方法

コードの改修は不要です。

1. スプレッドシートに `{学年}_{教科}`（例：`5年_算数`）と `{学年}_単元ガイド`（例：`5年_単元ガイド`）のシートを同じ20列／8列フォーマットで追加します。
2. `マスタ_教科一覧` シートに新しい行を追加し、`is_active` を `TRUE` にします。
3. 静的JSONキャッシュも更新する場合は `data/` 配下に該当JSONと `data/meta.json` を更新します。

## ディレクトリ構成

```text
.
├── index.html             # SPA エントリーポイント
├── css/style.css          # UD配慮・レスポンシブデザインシステム
├── js/
│   ├── app.js             # ルーティング・画面管理・演習フロー
│   ├── config.js          # GAS API URL・スプレッドシートID設定
│   ├── dataLoader.js      # 静的JSONキャッシュ + GASライブ同期
│   ├── scorer.js          # 全11タイプの正規化・別解・同値採点エンジン
│   ├── renderers.js       # ルビ/分数/縦書き変換＆11種問題UIレンダラー
│   ├── canvas.js          # 計算メモ・漢字マス・作図キャンバス
│   └── logger.js          # プロフィール管理・localStorage履歴・スコア送信キュー
├── data/                  # 静的JSONキャッシュ（全4教科・単元ガイド・マスタ）
├── assets/svg/            # 全4教科オリジナルSVG図版
├── gas/Code.gs            # Google Apps Script Web API（doGet / doPost）
└── scripts/               # 整合性検証＆スプレッドシート一括同期スクリプト
```
